# ExpediNap-Tech Backend API 🚀

Esta es la infraestructura robusta que alimenta el ecosistema de **ExpediNap-Tech**. Una API RESTful diseñada para la escalabilidad, seguridad y una integración fluida con Inteligencia Artificial.

## 🛠️ Tecnologías Utilizadas

* **Node.js & Express:** Motor principal del servidor.
* **MongoDB Atlas:** Base de datos NoSQL para persistencia de datos.
* **Google Gemini AI (3-Flash):** Integración de IA para asistencia virtual personalizada.
* **Cloudinary:** Gestión y almacenamiento de imágenes en la nube.
* **Helmet & Rate Limit:** Capas de seguridad avanzada para protección contra ataques comunes.
* **Compression:** Optimización de respuesta para un rendimiento ultra rápido.

## 🌟 Características Principales

* **IA Multi-turno:** Chatbot inteligente con memoria de conversación (history state).
* **Gestión de Proyectos:** CRUD completo con soporte para carga de imágenes.
* **Autenticación:** Sistema de usuarios seguro para administración de contenidos.
* **Seguridad Pro:** Implementación de CORS dinámico, Helmet para cabeceras seguras y limitación de peticiones globales.
* **Auto-Ping System:** Utilidad integrada para mantener la persistencia del servidor en entornos de despliegue.
